# ad_robot_test
this is test case for Ad robot


Написать скрипт-замерятель скорости интернета со своего компьютера.

Он должен принимать адрес, куда стучаться (какая-нибудь тяжелая картинка) , запускать последовательно 10 запросов к этому адресу, дожидаться ответа, вычислять среднее время запроса, объем скачанных данных и печатать в консоли скорость мб/с.

Ответ залить на github и дать репозиторий с инструкциями.

## Запуск

```bash
python main.py <url>
```

Например:

```bash
python main.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Скрипт делает 10 последовательных запросов и выводит время и размер каждого, среднее время запроса, общий объём и скорость в МБ/с. Количество запросов задаются константами `COUNT_REQUEST` в `main.py`.
